# Harness notes: Cursor (IDE, CLI, cloud agents)

> Tech Writer draft for ADR-0020 (Revision 13). Repo path: `docs/agents/harness-cursor.md` (new; adopted into ADR §1's tree, OQ-3). Harness-specific; the rules live in `AGENTS.md` and [`workflow.md`](workflow.md). Full mapping tables: [`adapters.md`](adapters.md).

**Everything Cursor-side is steering or best-effort, not enforcement (ADR §6 H2).** Enforcement is CI, the `main` ruleset (PENDING, DEP-R1; its GitHub Pro plan precondition is met, rev 10) and human gate-3 review.

**Cloud agents push as the Cursor GitHub App (rev 10),** not as `llevintza`. The same rules apply; the App must not be on the ruleset's bypass list. Its repo permissions: Administration **read** (it can't edit rulesets or branch protection), but Actions, Workflows and Merge-queues **write**, plus Contents, Pull-requests and Checks write, so it sits in the OQ5 admin scope for Actions and Workflows writes (H8, H15).

## Thin adapter files

- **Instructions: none.** Cursor reads `AGENTS.md` natively. Don't add `.cursor/rules/*.mdc` copies of AGENTS.md by hand (D4), `.cursorrules`, or `.cursor/commands/` (D8).
- **Generated by `scripts/agents/generate.mjs` only** (ADR §2; hand edits fail D7/D14):

| File | Content | Status |
|---|---|---|
| `.cursor/cli.json` | `{"permissions":{"allow":[…],"deny":[…]}}` only, colon form `Shell(cmd:args)`; no marker key (U8) | Steering |
| `.cursor/hooks.json` | `{"version":1,"hooks":{"beforeShellExecution":[{"command":"node scripts/agents/hooks/guard.mjs"}]}}` (H8) | Backup alongside DEP-R1; removed if the H8 condition fails (fallback (ii)). Grok Build reads it too (C7, rev 10) |
| `.cursorignore` | Derived from the Claude `Read(...)` denies | Steering |
| `.cursor/rules/areas/<area>.mdc` | Only if `cursorAreaRules: true` (U1 fails): `alwaysApply: false`, `globs: <dir>/**`, body = generated copy of the nested AGENTS.md | Fallback |

With this tree, the U1 fallback would emit seven `.mdc` files, one per nested node: `src/Desk.Api/**`, `src/Desk.Data/**`, `src/Desk.Seeder/**`, `src/Desk.UserAdmin/**` (rev 11, H19), `web/**`, `.github/**`, `deploy/**`. None counts toward D13 (`alwaysApply: false`).

## Permissions: expected `.cursor/cli.json` (generator output, preview)

Derived mechanically from the Claude draft by the rev 9 mapping (`Edit`→`Write`, drop `!`, `Bash(cmd args)`→`Shell(cmd:args)`, `*curl*`/`*wget*`→`Shell(curl)`/`Shell(wget)`, no `Shell(git:push)`). Preview file in the drafts folder: `_inputs/cursor-cli.preview.json`. Do not commit a hand-written copy.

- deny (70; `MIN_DENY_CURSOR` 70, rev 10, re-verified in `r10-verify.txt`): 6 `Read`/`Write` `**/` denies; the 21 colon-form push/merge denies (`Shell(git:push * main)` … `Shell(gh:pr --repo* merge*)`); the 28 admin denies with `Shell(curl)`, `Shell(wget)`; the 14 flag-before-verb denies (`Shell(gh:-*)` … `Shell(gh:api -*)`); the lease deny `Shell(git:push *--force-*)` (rev 10).
- allow (6): `Shell(dotnet:build *)`, `Shell(dotnet:test *)`, `Shell(npm:run lint)`, `Shell(npm:test *)`, `Shell(git:status)`, `Shell(git:diff *)`.
- Must **not** contain `Shell(git:push)` or `Shell(git:push*)` (H7, H11).
- No `ask` list exists in Cursor (TR), so the Claude `ask` entries for steering paths have no equivalent.
- **Web fetch:** Cursor's web fetch tool is the docs path (H16 (3)); it prompts unless `WebFetch(<domain>)` is allowed. The preview adds none.

## How each workflow rule is backed in Cursor

| Rule | `cli.json` (steering) | Guard (imported hook / `hooks.json`) |
|---|---|---|
| No push to `main` | 13 narrow colon-form patterns | Resolves destinations; blocks unless provably not `main` |
| Never force-push | `Shell(git:push *--force)`, `*--force *`, `-f*`, and the lease deny `*--force-*` (rev 10) | G9 blocks every force form, lease included (rev 10); `gh pr update-branch --rebase` blocks (guard only) |
| No curl/wget, no exception | `Shell(curl)`, `Shell(wget)`: first token only, so `env curl`, `/usr/bin/curl`, `sh -c 'curl …'` are guard-only | Word match anywhere (G18); hidden or copied names fail closed (G20/G21, rev 10) |
| gh canonical | 14 flag-before-verb denies | allowlist (G14, G15) |
| No merge / admin / Actions writes | merge + 28 admin denies; `Mcp(...)` steering denies | no allowlisted verb reaches them; MCP matcher `MCP:.*` generated for Cursor (rev 10; UNVERIFIED, U22) |
