# Start a phase

1. Confirm Tech Coordinator kicked the phase off and the previous PR merged (root item 7). Do not start the next §15 phase yourself.
2. Fetch and branch from fresh `origin/main`: `phase-N/<slug>` (README §15).
3. List the phase's ADRs (reserved numbers in `docs/adr/README.md`) and the Definition of Done.
4. Read the nested `AGENTS.md` for every area you will touch, and the matching guideline under `docs/agents/guidelines/`.
5. Stop after opening the phase PR and wait for review.
